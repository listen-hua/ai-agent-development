# 飞书资料源配置

系统支持两类飞书资料源：云空间文件夹和知识库页面。两者都使用企业自建应用的 `tenant_access_token` 读取，不需要额外事件回调；现有长连接继续负责机器人消息。

## 1. 开通应用权限

在飞书开放平台进入当前企业自建应用的“权限管理”，申请并由企业管理员审批以下只读权限：

- 云空间文件：`drive:drive:readonly`。
- 新版文档：`docx:document:readonly`。
- 知识库节点信息：`wiki:node:read`。
- 知识库子节点列表：`wiki:node:retrieve`。
- 若需要同步电子表格或多维表格，再申请对应的查看、评论和导出权限。

权限名称可能随飞书控制台版本调整，以 OpenAPI 调试台显示为准。权限变更后必须创建并发布新的应用版本，线上应用身份才会取得新增权限。

## 2. 给应用授予资料访问权

API scope 只表示应用具备调用接口的能力，应用还必须被授予目标文件或知识空间的阅读权限。

1. 确认应用已启用机器人能力，并已发布到当前企业。
2. 新建内部群，例如“行政 AI 资料同步”。
3. 在群设置中添加群机器人，选择本项目的企业自建应用。
4. 云空间文件夹：把最上层文件夹共享给该群，并授予可查看、可下载权限。
5. 飞书知识库：在知识空间设置中把该群添加为成员/阅读者；如果只同步部分内容，也可以仅把目标根页面及其子页面共享给该群。

只需授权准备同步的最上层目录或根页面。系统会递归遍历其子文件夹或子页面。应用可用范围也要包含执行配置的知识管理员。

## 3. 在管理后台连接

1. 使用知识管理员或超级管理员身份打开“制度知识库”。
2. 点击“连接飞书”，选择“云空间文件夹”或“飞书知识库”。
3. 文件夹可粘贴包含 `/drive/folder/fld...` 的链接或 `fld...` Token。
4. 知识库可粘贴包含 `/wiki/wik...` 的页面链接或 `wik...` 节点 Token。系统会先解析节点的 `obj_token` 和 `obj_type`，再读取当前页面及全部子页面。
5. 配置新文档的默认可见范围。这里是本系统 ACL，不等同于飞书源资料的协作者权限。
6. 点击“连接并开始同步”。首次同步生成草稿文档；确认内容和 ACL 后逐个发布，发布版本才会进入员工问答检索。

服务每 15 分钟自动增量同步，也可以点击资料源卡片立即同步。源内容变更时会新增草稿版本，不会覆盖线上已发布版本；源文件删除或应用失去访问权后，对应文档会停止参与检索，历史版本仍保留用于审计。

## 4. 支持范围

- 飞书知识库中的新版文档、旧版文档、电子表格和多维表格。
- 云空间中的上述在线文档，以及 PDF、DOCX、PPTX、XLSX、HTML、TXT、Markdown 文件。
- 单个下载文件最大 64 MB，单个资料源最多递归发现 10,000 份文档。
- 暂不解析飞书思维导图和在线幻灯片对象；无法识别的类型会计入“跳过”。

如果同步提示权限不足，先检查应用版本是否已发布、Wiki 两项 scope 是否已获批，以及应用机器人所在群是否确实拥有目标知识空间或根页面的阅读权限。
